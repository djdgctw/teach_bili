## 📝 算法说明

### 向量加法算法
向量加法是最基础的并行计算算法，将两个相同长度的向量对应元素相加。

**算法描述:**
```
给定两个长度为n的向量 A 和 B，计算向量 C = A + B
即：C[i] = A[i] + B[i], 其中 i = 0, 1, 2, ..., n-1
```

**计算特点:**
- **时间复杂度**: O(n) - 每个元素需要一次加法运算
- **空间复杂度**: O(1) - 只需要常数级别的额外空间
- **并行度**: 高 - 所有元素运算完全独立

## 📈 HLS优化特性

- **流水线设计**: 循环使用 `#pragma HLS PIPELINE` 优化
- **内存接口**: 三个独立的AXI4 Master接口
  - `gmem0`: 输入向量A
  - `gmem1`: 输入向量B  
  - `gmem2`: 输出向量C
- **控制接口**: AXI4-Lite接口用于参数传递
